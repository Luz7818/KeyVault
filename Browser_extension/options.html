    批量导入

    粘贴 .env / JSON / curl 文本。只入可信候选；不可信的进「跳过」（只有掩码预览，不含值）。标签逗号分隔，可选。

    导出加密备份

    整库导出为 KVBE1 口令加密文本（PBKDF2 60 万轮 + AES-GCM），下载到本机。口令是唯一防线：丢失无法恢复，弱口令等于没加密。

    从备份恢复

    恢复把备份里的记录合并进当前库：重名同值自动跳过，不覆盖已有记录。整库清除后重建：先用同一主密码设置保管箱（回到解锁态），再恢复。

    网页版泄露扫描

    把库里的全部指纹（含已吊销的旧值）当搜索模式。桌面 kv scan 目录的浏览器等价：只扫描你显式提供的代码，目录遍历与 .git 剪枝由你选择的范围天然替代。分批发送（每批 ≤100 条 / ≤400 万字符），头 8KB 含空字节的二进制与超 50MB 的文件自动跳过并计数，读不了的项目会明确列出。
