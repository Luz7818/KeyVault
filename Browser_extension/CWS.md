## 单一用途声明（Single purpose）

KeyVault 是一个**本地密钥保管箱**：在网页上复制 API 密钥时自动检测，经用户
确认后用主密码派生密钥（AES-GCM-256）加密存入浏览器本机数据库（IndexedDB），
供用户随后搜索、复制（30 秒自动擦除剪贴板）、生成随机密码与批量导入。
**所有数据只保存在用户本机，不向任何服务器发送**（全仓运行时代码无
`fetch` / `XMLHttpRequest` / `WebSocket` / `sendBeacon`，可 grep 复核）。

## 逐权限理由（Permission justifications）

manifest.json 的权限恰为四项 API + 一项主机权限 + 一个内容脚本声明
（`manifest.json:8-21`）；每条都写「声明用途 = 实际行为」，并列出反证
（我们不做的事）。

### `storage`

- **声明用途**：保存扩展的会话状态。
- **实际行为**：只使用 `chrome.storage.session`（绝不碰 `chrome.storage.local`），
  且只写三个键——解锁后的原始密钥字节（base64）、自动锁定的活动时间戳、
  在飞剪贴板擦除的元数据（`background.js:52-59,68-72,114-125`）。键集合有
  测试钉死：只允许这三个键、全量序列化不含任何明文值
  （`tests/app-background.test.js`「storage.session 卫生」节）。浏览器会话
  结束即清空；锁定 = 删除密钥键（`src/vault/crypto.js:122-126`）。
- **不做**：不存密钥明文（密文在 IndexedDB）、不存设置（设置在 vault 库内）、
  不做跨会话追踪。

### `alarms`

- **声明用途**：本地定时器，两个用途。
- **实际行为**：① 每分钟的自动锁定检查（空闲超过 `autoLockMinutes` 锁库，
  `background.js:179-193` 与 alarm 注册 `background.js:634`）；② 复制后
  30 秒的一次性擦除闹钟（`background.js:112-121`），到点经 offscreen 页覆盖
  剪贴板；扩展重载后由启动 sweep 补挂/补擦（`background.js:178-193`）。
- **不做**：不定时联网、不做统计上报。

### `clipboardWrite`

- **声明用途**：把用户主动要求复制的内容写入剪贴板，以及到期后覆盖擦除。
- **实际行为**：① popup / 管理页的复制（reveal 后 `navigator.clipboard.
  writeText`，`popup.js` 复制流与 `options.js:591,757,769`）；② 密码生成器
  结果的复制（复制即安排 30 秒擦除）；③ **擦除本体**：offscreen 页在无用户
  手势的上下文里把剪贴板覆盖为固定提示文本 `KeyVault: clipboard cleared`
  （`offscreen.js:21-23`）——没有用户手势还能写剪贴板，正是这条权限存在
  的原因。
- **不做**：不读剪贴板（**绝不申请 `clipboardRead`**——内容脚本只用 copy/cut
  事件拿用户主动复制的内容，见 `manifest.json` 权限面与 README「别动」节）；
  不在用户未触发复制时写剪贴板（擦除覆盖除外）。

### `offscreen`

- **声明用途**：MV3 service worker 没有剪贴板访问能力，擦除动作需要一个
  屏幕外文档来执行。
- **实际行为**：创建唯一的 offscreen 文档（`background.js:139-150`，理由字段
  原文 `"30 秒 TTL 到期后把剪贴板覆盖为无密文的安全提示文本"`），该文档只做
  一件事：收到 `{target:"offscreen", kind:"wipe-clipboard"}` 时覆盖剪贴板并
  响应（`offscreen.js:15-31`），其余消息一律不响应。
- **不做**：不加载远程内容、不播音频、不读页面。

### `host_permissions: <all_urls>` + `content_scripts: <all_urls>`

- **声明用途（与实际行为一致）**：KeyVault 的核心场景是「用户在**任意**网站的
  控制台/仪表盘里复制 API 密钥」——无法枚举域名白名单，因此内容脚本声明
  `<all_urls>` 注入。内容脚本只做四件事，全部围绕用户主动的复制动作：
  ① 监听 `copy` / `cut` 事件（`content.js:375-376`，`isTrusted` 防伪造：
  复制路径 `content.js:292`、提示条按钮 `content.js:213,219`）；② 从事件里取**这一次**被复制的选中文本（8–200 000
  字符闸，`content.js:34-35`），交给 service worker 本地检测（`content.js:308-316`）；
  ③ 恰有一条可信候选时弹 closed Shadow DOM 确认条（`content.js:19,105,176`），
  用户点「存入」才回传入库（`content.js:212-220,342-344`）；④ 复制发生即通知 SW 取消在飞的剪贴板
  擦除（`content.js:295`）。`host_permissions` 与内容脚本范围相同、成对声明
  （`manifest.json:10,15-21`），保持权限提示与实际注入范围同一口径。
- **不做（与声明同等重要）**：不读页面其他内容（表单、DOM、cookies、浏览
  历史一概不碰——唯一的输入就是 copy/cut 事件携带的选中文本）；不持久化
  未确认的候选（确认条关闭即丢弃，20 条去重环只存内容指纹不存文本，
  `content.js:40`，环内不存文本）；**扩展任何上下文都不发起网络请求**；不注入页面样式
  以外的行为（确认条挂在 Shadow DOM，`content.js:206-220`）。

## Privacy 面板逐项（开发者控制台「隐私权」标签页）

| 表单项 | 填写内容 |
|---|---|
| 单一用途说明 | 见上文「单一用途声明」，可整段粘贴 |
| 是否处理用户数据 | 是——勾选「用户提供或网站内容产生的信息（网页上复制的文本）」与「本地存储的用户活动」（复制/存入/解锁等操作时间戳，仅在本机） |
| 是否收集（传输走本机之外） | **否**——全部处理在本机完成，无任何网络传输 |
| 是否出售或用于无关用途 | **否**——无广告、无信用评级、无放贷用途 |
| 隐私政策 URL | 发布 `PRIVACY-POLICY.md` 后得到的公开 URL（发布步骤见 PUBLISHING「渠道一」前置） |
| 安全实践（勾选） | 传输加密（无传输，N/A 但按表勾「不适用」口径如实填写）；加密静态数据（是：AES-GCM-256，密钥由主密码 PBKDF2-SHA256 60 万轮派生）；数据保留（用户自控：库内记录保留到用户删除/清库/卸载；复制的文本未确认即弃）；本库无远程代码（**不使用远程托管代码**——MV3 全部代码打进发布包，`make_release.py` 清单冻结） |
| 合规声明 | 扩展不涉及受限类目；数据处理声明与「数据不出本机」一致 |

## 版本发布说明 v1.0.0（商店「版本说明」/ GitHub Release 共用）

首个公开发布版本。一个本地优先的密钥保管箱，全部数据只存本机浏览器：

- **页内捕获**：复制 API key 自动检测（24 类平台形态），可信候选弹确认条，
  点「存入」才加密入库，绝不悄悄收。
- **加密保管**：主密码 PBKDF2（60 万次派生）+ AES-GCM-256，数据只存本机
  IndexedDB；无操作自动锁定（默认 15 分钟，0–240 可调；锁定只认扩展内的
  交互，网页上复制别的内容不会续命）。
- **快速取用**：popup 搜索 → 一键复制 → 30 秒后剪贴板自动覆盖（期间你复制
  了新内容则取消擦除，绝不覆盖你的新东西）。
- **密码生成器**：`crypto.getRandomValues` + 拒绝采样（无模偏差），长度
  8–128、四字符类开关、可排除易混淆字符（Il1O0o），每个启用的字符类至少
  一枚，熵粗估展示；复制走同一条 30 秒擦除通道。
- **批量导入向导**：Bitwarden CSV / JSON 导出、otpauth:// 验证器导出清单、
  .env 键值文本，格式自动识别；两步流程（解析预览 → 勾选确认），跳过的
  不可信条目只显示掩码预览与原因。
- **两步验证码**：值是 base32 种子的记录可显式打开 TOTP 活码（RFC 6238，
  倒计时环，剩 5 秒转琥珀）。
- **泄露扫描**：粘贴文本或选文件/目录，用已存指纹在本机逐行比对，命中逐条
  报告文件与行号。
- **审计与轮换**：append-only 审计链整链可验；轮换保留历史指纹供扫描旧泄露；
  设平台、纠正规则、重命名、吊销、过期标记。
- **加密备份**：口令加密的 KVBE1 备份导出/恢复，错误口令显式区分。

已知限制（如实声明）：浏览器没有「排除系统剪贴板历史」的 API，剪贴板写入
无法像桌面版那样排除 Win+V 与云剪贴板（popup 文案如实提示）；30 秒擦除
需要浏览器存活；扩展与桌面版功能同源、数据各自独立。
