# KeyVault 浏览器扩展隐私政策（v1.0.0，2026-11-12 生效）

> 用途：Chrome Web Store / Edge 加载项提审要求的隐私政策定稿原文——发布到
> 公开 URL（如 GitHub Pages 的 `keyvault-privacy.html`）后，把该 URL 填进
> 商店「隐私权」标签页。本页即发布原文，逐条与扩展实际行为对位，代码行为
> 变了先改这里。提审表单逐项填写见 [`CWS.md`](CWS.md)。

KeyVault 是一个**本地优先**的密钥保管箱浏览器扩展。本政策说明它处理哪些
信息、存在哪里、和谁共享。一句话版本：**我们不收集、不传输、不出售任何
数据——扩展没有服务器，也没有遥测。**

## 1. 我们处理哪些信息（全部在本机处理）

| 信息 | 何时处理 | 处理方式 | 是否离开本机 |
|---|---|---|---|
| 你在网页上复制的文本 | 你按下复制/剪切的那一刻 | 只读取这一次复制事件携带的选中文本，在本机检测是否为 API 密钥形态；不是可信候选则即时丢弃，不保留副本 | 否 |
| 你确认存入的密钥值 | 你在确认条或管理页点「存入」 | 用你的主密码派生密钥（PBKDF2-SHA256 60 万轮 + AES-GCM-256）加密后写入本机 IndexedDB | 否 |
| 主密码 | 创建/解锁保管箱 | 不存储明文，只在本机存派生密钥与校验器 | 否 |
| 操作记录（存入/复制/轮换等） | 对应操作发生时 | 写入本机审计日志（内容不含密钥值，只有名称快照与值长度/指纹前缀） | 否 |
| 剪贴板内容 | 你主动复制、或到期自动擦除 | 擦除 = 用固定提示文本覆盖剪贴板，全程本机 | 否 |
| 泄露扫描的文本 | 你手动粘贴/选择文件 | 与本机已存指纹比对，文本不离开浏览器 | 否 |

## 2. 数据存在哪里、保留多久

- **密钥数据**：本机浏览器 IndexedDB，密文存储。保留到你删除该条、使用
  「整库清除」、轮换后按吊销语义保留旧指纹（用于扫描历史泄露），或卸载
  扩展（随浏览器存储一并清除）。
- **会话状态**：`chrome.storage.session` 只存解锁密钥的字节（base64）、
  自动锁定的活动时间戳与在飞擦除的元数据；浏览器会话结束即清空，锁定
  即删密钥键。
- **剪贴板**：写入来自你的主动操作；复制后 30 秒由扩展自动覆盖为提示
  文本（需要浏览器存活）；期间你复制了新内容则取消覆盖。
- **已知限制**：浏览器的剪贴板历史（Win+V）与云剪贴板由操作系统管理，
  扩展没有排除它们的 API——桌面版有，浏览器版没有，这是平台边界而非
  附加收集。

## 3. 我们和谁共享

**没有任何第三方共享。** 扩展不接入分析、统计、崩溃上报或广告服务；运行
时代码不含任何网络请求（无 fetch / XHR / WebSocket / beacon，可在开源仓库
复核）。发布包内的全部代码随包分发，**不加载任何远程托管代码**。

## 4. 你拥有的控制权

- **锁定**：无操作自动锁定（默认 15 分钟，0–240 分钟可调），随时手动锁定。
- **删除**：管理页「整库清除」需主密码与确认短语双门，删除本机全部数据；
  卸载扩展等效。
- **导出**：可随时导出口令加密的 KVBE1 备份文件，数据可随身携带。
- **不确认即不留**：捕获确认条点「忽略」或直接关闭，该次复制的文本立即
  丢弃。

## 5. 未成年人

扩展面向开发者与运维人员的密钥管理，不面向儿童收集任何信息。

## 6. 政策变更

行为变化会先改本页并随扩展版本发布；重大变化在商店「版本说明」中提示。
本页与代码的对应关系由开源仓库维护，欢迎对照审查。
